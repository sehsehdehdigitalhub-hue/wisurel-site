Receipt processing

What the AI reads from a receipt

The fields below are the ones the extraction asks for. Each can be corrected before a record is approved.

Fields extracted

DateDescriptionAmountDebit or creditCategorySenderRecipientBankReferenceNotes

Categories follow the list set for the farm: feed, salaries, fuel, construction, medical, utilities, office, transfers and other.

What the record can show

Ready to approvePossible duplicateCheck details

A possible duplicate lists its reasons: same amount, same date or a day apart, similar description, and same reference number if there is one. You can keep both, mark it as a duplicate, or decide later. Nothing is erased; removed items stay in a bin until you restore or leave them.

Quality depends on the photo and the document. Blurred or cropped receipts are the most likely to need checking.

Bank reconciliation

Check a statement against your records

Upload your bank statement as CSV or Excel. Wisurel compares each line with approved records and lists what doesn't line up.

1

Upload

Upload a CSV or Excel export from your bank. Dates and amounts are read from the common column names.

2

Match

A line matches a record when the amount is the same and the dates are within five days of each other.

3

Review

Lines that didn't match are listed on their own, so you can see what needs attention.

Statuses you will see

MatchedBank line with no receiptReceipt not in the bankPossible duplicateNeeds review

Matching uses amount and date only, so two different payments of the same amount on nearby days can match each other. Check the lines it lists before relying on the result.

Security and trust

What is protected, and how

Each point below is in the code today. Some depend on the setup in the README, and that is said where it applies.

Sign-in

Accounts sign in with Supabase Auth. Sign-up needs an invite code, checked by the database.

Separation between workspaces

Every table has row-level security tied to your workspace, so a signed-in account can only read its own workspace's records.

Roles checked on the server

Owners and admins change roles through database functions that check the caller. A member cannot raise their own role.

AI key kept off the page

In a connected workspace the AI key is held as a server secret, and the page calls a function that checks who is asking.

Scheduled jobs protected

The weekly digest and the processing run need a secret from the scheduler, so a stranger cannot trigger them.

WhatsApp requests verified

When the app secret is set, every webhook request is checked against Meta's signature before anything in it is trusted.

What is not claimed

Wisurel holds no certification: not SOC 2, ISO 27001, GDPR or PCI. No independent security audit has been carried out. The app keeps no AI key in the browser. Records are stored in the farm's own database, behind sign-in. The database rules are tested as written, and should be checked on your own project before real data goes in (README sections 15 and 21).

FAQ

Questions people ask

What is Wisurel?

An internal records tool for Wisurel Ogbomosho Farm. It reads receipts and documents, keeps the approved records, checks bank statements, and produces reports and a weekly digest.

Who is it for?

The farm's staff and management. It is built for Wisurel's own operations and is not offered to other businesses.

Does it work on a phone?

Yes. It is laid out for phones and checked at widths from 320 to 412 pixels, and the camera can be used to capture receipts.

Can staff report through WhatsApp?

Yes, once WhatsApp Business is connected (README section 4). Until then, no messages arrive and the Daily Reports page says so.

Do staff need an account?

To use the app, yes: an account and an invite code. Reporting by WhatsApp needs only the staff member's number to be registered.

How does receipt processing work?

The AI reads the photo or document and fills in the fields listed above. The records go to "Needs your review" if a repeat is found or a field can't be read; the rest are added to the ledger.

What happens when the AI can't read a receipt?

It is never silently accepted. An unreadable field is marked "Check details" and cannot be approved until it is fixed. If the whole extraction fails, the file shows as failed and can be retried.

Can I edit the extracted data?

Yes. Edit a record before approving it, or any time afterwards from the ledger. Changes are saved, and approved records remain editable.

Can I export my records?

Yes, as Excel, CSV, PDF, JSON, plain text, Markdown or Word. Reports can be exported the same way.

Can I reconcile a bank statement?

Yes, from a CSV or Excel export. Lines are matched on amount and date, and the lines that don't match are listed.

Does Wisurel store my documents?

Uploaded files are kept in your workspace's private storage, and only signed-in members of that workspace can read them. The app does not yet delete stored files when a record is removed.

Where is the AI key stored?

It is a server secret on the farm's Supabase project and never reaches the browser.

Does it work offline?

No. Processing needs an internet connection, and the app loads its libraries from the web.

What does a connected setup need?

A Supabase project, an Anthropic API key, hosting for the app (GitHub Pages works), and, if wanted, WhatsApp through Meta and email through Resend. The README lists each step.

How much does WhatsApp cost?

Meta charges according to its own pricing, which depends on message type and country. Check Meta's current price list before relying on any figure.

Can I create my own automations?

Yes. Describe the process, review the proposed columns, then confirm. Nothing is recorded until you do.

Can several people use it?

Yes. Owners and admins invite others with a code and a role: member, admin, or owner.

How is access separated?

Each workspace's records are protected by row-level security in the database. The app is set up for one workspace, the farm's.
